# Dungeon and Endgame Source Protection

## Core principle

Performance and replacement cost are separate dimensions.

A strong dungeon weapon may deserve more protection than a similarly performing world drop because the exact roll can be expensive to reproduce.

## Verify

Before deletion, identify:

- Actual acquisition source
- Dungeon or raid name
- Encounter or quest
- Current obtainability
- Required difficulty
- Tier, crafting, or Adept status
- Unique origin trait or perk combination
- Whether it is the player's only copy
- Time and access required to reacquire it

## Do not confuse

- Dungeon-exclusive source
- Proven useful in a dungeon
- Suitable for dungeon encounters
- A build card labeled “Dungeon”

Only the first is an acquisition property.

## Decision rule

Dungeon source is a strong retention bonus, not automatic immunity. Delete only when the roll is truly dominated, no meaningful coverage is lost, metadata is protected, and the replacement case is auditable.
