1. Extract the v2.8 GitHub update ZIP.
2. Copy the **contents** of the extracted folder into the root of the local `Destiny2-Vault-Project` clone, preserving the included `docs/` and `templates/` folders.
3. Allow matching files to be replaced.
4. Open GitHub Desktop and review the Changes list.
5. Confirm that no vault export, DIM import, workbook, or candidate audit changed.
6. Commit with a message such as:

   `Add Brent reasoning doctrine and evidence ledger`

7. Click **Push origin**.
